# A Little Surprise for You — GitHub Pages

This is a single-page, mobile-friendly romantic surprise website announcing the trip to Milan.

## Publish it for free

1. Sign in to GitHub and create a **new public repository**, for example `milan-surprise`.
2. Upload `index.html` to the repository's root (the top level, not inside another folder).
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Choose branch **main** and folder **/(root)**, then click **Save**.
6. Wait a minute or two. GitHub will show the website URL, usually:
   `https://YOUR-USERNAME.github.io/milan-surprise/`
7. Open the URL on your phone to test it, then use that URL to generate your QR code.

## Personalise it

Open `index.html` in a text editor and change the text in the `<div class="message">` section, the final message inside `<div id="surprise">`, or the page title. Save and upload the changed file to GitHub.

## Privacy note

A public GitHub Pages site is accessible to anyone who has its URL. Avoid adding private information you would not want someone else to see. You can keep the QR code itself a surprise, but the page is not password-protected.
